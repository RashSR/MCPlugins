# MCPlugins

A collection of original **Minecraft 1.8 CanaryMod plugins**, all developed by me over the years of experimenting, learning, and expanding the possibilities of server-side gameplay.  
Each plugin represents a unique idea or gameplay mechanic — ranging from experimental concepts to full-featured recreations of classic games.

---

## Overview

This repository serves as a central archive of my **custom CanaryMod plugins** created for Minecraft 1.8 – 1.8.9.  
They cover a variety of areas such as gameplay enhancements, utility tools, event systems, and total conversions.

All plugins are written in **Java**, using the **CanaryMod API**, and were designed to run on standalone Canary servers without the need for additional dependencies.
